# 税务法规核对规则

你帮助比较企业申报数据与法规要求，找出差异并标记风险。

## 通用核对规则(全国适用)

### 增值税 (VAT)

| 检查项 | 正常范围 | 风险信号 |
|--------|----------|----------|
| 税负率 | 一般纳税人 1.5%-6%(行业差异) | 税负率 < 行业均值 60%，或 < 1% 持续 2 季度以上 |
| 进销比对 | 进项税额 / 销项税额 ≈ 70%-90% | < 60% 或 > 95%(留抵异常) |
| 发票连号 | 单季度无 ≥5 张连号来自同一开票方 | 连号 ≥5 张，相同对方，金额相近 |
| 进项税额转出 | 免税/简易计税项目对应进项税额全额转出 | 有进项发票但未转出 |
| 留抵退税 | 存量/增量留抵与账面一致 | 账面未核算、进项发票未勾选 |

### 企业所得税 (CIT)

| 检查项 | 正常范围 | 风险信号 |
|--------|----------|----------|
| 季度预缴率 | 预缴额 / 全年预估应纳额 ≥ 70% | < 60%，汇算清缴可能面临补税+滞纳金 |
| 收入确认 | 银行流水收款 = 开票金额(±5%) | 收款 > 开票(漏报收入)；开票 > 收款(虚开发票) |
| 成本费用率 | 营业成本/营业收入 = 60%-95% | > 95%(毛利异常低)；< 40%(可能隐藏收入) |
| 三项费用 | 业务招待费 ≤ 发生额60%且 ≤ 收入5‰；广宣费 ≤ 收入15% | 超比例未纳税调增 |
| 关联交易 | 关联方交易价格偏离市场价 ≤ 10% | 价格异常偏低转移利润 |

### 个人所得税 (IIT)

| 检查项 | 正常范围 | 风险信号 |
|--------|----------|----------|
| 申报人数 | 个税申报人数 = 社保参保人数(±5%) | 差异 > 5% 或 > 3人 |
| 工资基数 | 平均工资在市平工资 60%-300% 之间 | 全员按最低基数申报 |
| 劳务报酬 | 单笔 > 800 元均代扣代缴 | 有劳务费但无代扣记录 |

### 印花税

| 检查项 | 风险信号 |
|--------|----------|
| 购销合同 | 合同金额 × 0.3‰ vs 实缴，差异 > 20% |
| 借款合同 | 借款金额 × 0.05‰ vs 实缴 |
| 实收资本 | 实收资本增加额 × 0.25‰ 是否申报 |

### 城建税及附加

城建税 = (增值税+消费税) × 税率(7%/5%/1%)
教育费附加 = (增值税+消费税) × 3%
地方教育附加 = (增值税+消费税) × 2%

| 检查项 | 风险信号 |
|--------|----------|
| 计税基础 | 附加税计税基础 ≠ 增值税实缴 + 消费税实缴 |
| 城建税率 | 市区7%、县城/镇5%、其他1%，确认适用是否正确 |

## 地区差异速查

### 北京
- 城建税率 7%
- 增值税小规模纳税人：月销售额 ≤ 10万(季度30万)免征
- 企业所得税：高新技术企业按 15%

### 上海
- 城建税率 7%
- 临港新片区：重点产业企业按 15%
- 小微企业"六税两费"减半征收延续

### 广东(深圳除外)
- 城建税率 7%(市区) / 5%(县城)
- 大湾区个人所得税优惠政策(境外高端人才补贴)

### 深圳
- 城建税率 7%
- 前海深港合作区企业所得税 15%

### 浙江
- 城建税率 7%(市区) / 5%(县城)
- 小微企业普惠性税收减免

### 江苏
- 城建税率 7%(市区) / 5%(县城)
- 园区类政策多(苏州工业园区等)

### 其他地区
地区法规细节存放在 `regulations/<地区>/` 目录。核对时将企业所在地区的具体政策与通用规则叠加适用。

## 核对输出格式

差异清单每行：
```markdown
| 税种 | 检查项 | 申报数 | 账面数 | 差异 | 可能原因 | 风险等级 | 整改建议 |
|------|--------|--------|--------|------|----------|----------|----------|
| 增值税 | 进销项比 | 进项85万 | 进项62万 | -23万 | 部分发票未认证 | 🟡 | 下季度补认证或转出 |
```

## 行业特定风险

| 行业 | 高风险点 |
|------|----------|
| 建筑 | 简易计税/一般计税混用、跨区域预缴、劳务分包发票 |
| 电商 | 平台收入未全额确认、刷单虚增收入、跨省开票 |
| 餐饮 | 未开票收入隐匿、农产品进项税额核定扣除、储值卡增值税处理 |
| 软件 | 即征即退核算不清、研发费用加计扣除证据链 |
| 制造 | 存货盘亏进项税额转出、出口退税单证不全 |
| 房地产 | 预售款预征增值税、土地增值税清算 |

## 法规文件格式

`regulations/<地区>/` 下的法规文件命名约定：
- `增值税_YYYY.md` / `VAT_YYYY.md`
- `企业所得税_YYYY.md` / `CIT_YYYY.md`
- `个人所得税_YYYY.md` / `IIT_YYYY.md`
- `税收优惠_YYYY.md` / `incentives_YYYY.md`

法规文件建议采用以下格式：
```markdown
# <税种> — <地区> — YYYY年度
## 适用税率
## 申报期限
## 优惠政策（截至YYYY-Qx）
## 重点稽查方向
## 常见处罚标准
```
