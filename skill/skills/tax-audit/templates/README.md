# 税务自查工作空间搭建

## 快速开始

```bash
# 1. 创建税务审计专用目录
mkdir tax-audit-workspace && cd tax-audit-workspace

# 2. 启动 deepx
deepx
```

然后告诉 deepx：
> "帮我搭建税务自查工作空间，企业名是 <企业名>，地区是 <地区>，行业是 <行业>"

## 目录结构

deepx 会自动创建：

```
tax-audit-workspace/
├── .deepx/
│   └── skills/              ← 项目级skill(可选,覆盖内置)
├── companies/
│   └── <企业名>/
│       ├── 2025Q1/           ← 每季度一个目录
│       │   ├── 进项发票/     ← 放扫描件/PDF/图片
│       │   ├── 销项发票/
│       │   ├── 银行流水/
│       │   ├── 完税凭证/
│       │   ├── 纳税申报表/
│       │   ├── 合同资料/
│       │   ├── metadata.json
│       │   ├── 发票汇总.csv
│       │   └── 季度自查报告.md  ← 最终输出
│       └── 2025Q2/
│           └── ...
├── regulations/             ← 可按地区补充地方法规
│   └── <地区>/
│       └── ...
└── README.md
```

## 工作流

启动 deepx 后直接说：

```
帮我做 <企业名> 2025年Q1 税务自查
```

deepx 会按 4 步执行：
1. **资料归档** — OCR 发票、整理银行流水、建立索引
2. **法规核对** — 按地区/行业规则逐项比对
3. **风险定级** — 🔴🟡🟢 分级每个差异项
4. **生成报告** — 输出 `季度自查报告.md`

## 准备资料

| 资料 | 格式 | 说明 |
|------|------|------|
| 进/销项发票 | 图片/PDF | 放到对应季度目录，deepx 会 OCR 提取 |
| 银行流水 | PDF/CSV | 含收入/支出明细 |
| 完税凭证 | PDF | 税务局出具的完税证明 |
| 纳税申报表 | PDF/CSV | 本期申报的各税种明细 |
| 合同资料 | PDF | 大额合同（影响印花税判断） |

## 内置 Skill

| Skill | 用途 | 加载时机 |
|-------|------|----------|
| `tax-audit` | 主工作流 | 启动时自动 |
| `tax-regulations` | 法规核对规则 | 工作流第二步 |
| `tax-audit-report` | 报告模板 | 工作流第四步 |

## 地区法规补充

在 `regulations/<地区>/` 下创建 Markdown 文件，命名格式：
- `增值税_YYYY.md`
- `企业所得税_YYYY.md`
- `个人所得税_YYYY.md`
- `税收优惠_YYYY.md`

deepx 会在核对阶段读取对应文件。

## 注意事项

- OCR 识别准确度取决于发票图片质量，关键金额建议人工复核
- 首次使用建议先用简单场景（单一企业、单一税种）验证流程
- 所有数据处理均在本地，不上传云端
