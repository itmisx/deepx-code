## 报告生成原则

1. **数据说话**：每个结论必须有数据支撑，不能凭空判断。
2. **分级表述**：风险用 🔴🟡🟢 可视化标识，一目了然。
3. **原因 + 建议**：每个差异项都要说明可能原因和可操作的整改建议。
4. **可追溯**：报告中引用的数据标注来源（OCR 识别的发票号码、银行流水文件等）。
5. **保守原则**：不确定时按较不利情况假设，宁可多提醒不漏风险。

## 生成后检查清单

- [ ] metadata.json 里的企业信息是否正确填入第一章
- [ ] 发票汇总.csv 的数据是否完整反映在第三章
- [ ] 差异清单的每一项是否都有对应整改建议
- [ ] 风险等级是否按照 tax-audit Skill 的标准评定
- [ ] 自查结论是否与风险汇总一致
- [ ] 文件保存路径是否为 `companies/<企业名>/<季度>/季度自查报告.md`
